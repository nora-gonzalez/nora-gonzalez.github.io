En este documento veremos una introducción a los conceptos básicos del ciclo de DAM y lo que abarca.

A continuación 4 tecnologias que veremos durante el curso:

  • HTML
    Lenguaje de marcado esencial para definir páginas web.
  • CSS
    Lenguaje utilizado para aplicar estilos a documentos escritos en lenguajes de marcado.
  • DOM
    Interfaz de programación que representa la estructura de un documento web como un árbol jerárquico de nodos.
  • XML
    Lenguaje de marcado extensible que permite definir etiquetas personalizadas para organizar información en una jerarquía lógica.

En este documento también veremos el paso a paso para hacer un commit y push desde Git como con la siguiente linea de código: System.out.println("Hola mundo");

  1. Hacemos los cambios en el código
  2. Guardamos los cambios
  3. Accedemos al repositorio local desde GitHub Desktop
  4. Hacemos un commit de los cambios con un nombre y descripción si se quiere
  5. Hacemos un "push origin" para actualizar el repositorio remoto
